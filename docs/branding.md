# BuildHeadway identity

The approved mark combines an H with a forward arrow, representing progress toward a completed goal. The blue symbol and BuildHeadway wordmark identify this project.

![BuildHeadway](../assets/brand/buildheadway-logo-on-white-v1.png)

| File | Size | Use |
| --- | --- | --- |
| [Transparent logo](../assets/brand/buildheadway-logo-v1.png) | 2172 × 724 | Full logo on a light background |
| [Square icon](../assets/brand/buildheadway-icon-v1.png) | 1254 × 1254 | App identification and avatars |
| [Logo on white](../assets/brand/buildheadway-logo-on-white-v1.png) | 2172 × 724 | README and other surfaces that need a consistent readable background |

All three are PNG assets. The transparent logo and icon retain their original alpha channel. Preserve their proportions and clear space when placing them.

These files ship in the source archive, extracted native distribution and npm package. They do not require a network download to read locally. The terminal command remains `buildheadway`; the artwork appears in documentation rather than introducing a graphical launcher.

GitHub upload and repository configuration are separate steps. Inclusion here does not mean an avatar or social preview has been uploaded to GitHub.
