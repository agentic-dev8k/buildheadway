# Terminal previews

`terminal-palette.png` and `terminal-conversation.png` retain the approved 0.30 terminal previews from the saved 0.32 distribution, with unchanged bytes. They were rendered from an actual Linux terminal capture using simulated model replies. They illustrate the interface; they are not new 0.33 execution evidence, authenticated model inference, or Windows/macOS screenshots.

See the [terminal guide](../terminal.md) for controls and the [validation record](../maintainers/validation.md) for checks performed on the current source.
